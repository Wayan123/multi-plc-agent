# Code of Conduct / Kode Etik

## English

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good intent, critique code and not people, and keep discussions on topic. Harassment, insults and personal attacks are not accepted.

Report unacceptable behaviour privately to the maintainer at the email address on the maintainer's GitHub profile. Reports are handled confidentially. Maintainers may edit or remove comments and contributions, or block contributors, that break these rules.

## Bahasa Indonesia

Proyek ini mengikuti [Contributor Covenant versi 2.1](https://www.contributor-covenant.org/id/version/2/1/code_of_conduct/). Singkatnya: saling menghormati, berprasangka baik, kritik kodenya bukan orangnya, dan tetap pada topik. Pelecehan, hinaan, dan serangan pribadi tidak diterima.

Laporkan perilaku yang tidak pantas secara privat ke maintainer lewat alamat email di profil GitHub maintainer. Laporan ditangani secara rahasia. Maintainer boleh mengubah atau menghapus komentar dan kontribusi, atau memblokir kontributor, yang melanggar aturan ini.
